# U2 browsable views

`main.rs` owns HWND, message routing, rendering, shell pool and focus-only caret timer.
`view.rs` composes kit widgets; `tab.rs` owns each EntryStore, Selection, enumeration,
filter, scroll and timing. `nav.rs`, `tabs.rs`, `cols.rs`, `sidebar.rs` hold navigation,
tab order, sizing and places. Theme comes from tokens via `tools/gen-tokens.ps1`.

Enumeration workers post coalesced wakes. UI drops stale generations, merges batches
into the sorted core store and draws only visible rows. First batch yields immediately
and bypasses paint throttling; subsequent pumps have a 6 ms budget. Closing tabs drops
stores/channels and cancels workers. Places and ShellExecute run on workers; icons and
native menus retain S4 STA ownership. Store validation failures become visible errors.

Keys: Ctrl+T/W, Ctrl(+Shift)+Tab; Ctrl+L/F4/Alt+D path; Alt+Left/Right/Up and Backspace;
Ctrl+F or typing filters, Escape clears/cancels; arrows/Home/End/PageUp/PageDown,
Shift extends selection, Ctrl+A selects all, Enter opens. Ctrl+Shift+L toggles theme,
Ctrl+Shift+D cycles 22/26/30 DIP density, Ctrl+Shift+Z toggles zebra. F5 refreshes.
Right-click/Shift+F10 opens native shell menu. No file operations added.

Startup navigation includes window creation: System32 first rows 53.64 ms from tab
creation, final frame 65.05 ms. This fails 30 ms if startup itself is counted as a
navigation; warm navigation above excludes startup. First-batch store times were
0.79–8.81 ms warm. Cold filesystem cache not tested.

Memory contributors: GPU render target/driver heaps, temporary software WARP target
at GPU handover, DirectWrite layouts/heaps, loaded shell handlers. Icon cache after
scroll: 624 entries / 2.49 MiB; too small to explain the overage. These contributors
are architectural observations, not a heap attribution trace. No renderer redesign.

Leak smoke (headless, 200 navigations over 64 folders + 50 tab open/close): private
2.1 -> 2.3 MiB (+0.25), handles 107 ->107, GDI/USER 0 ->0. This is not the full
10,000-navigation/1,000-tab GUI leak gate, and relative private growth exceeds 5%
on this tiny baseline. No claim that full leak gate passes.

Caret: one 530 ms timer while a text field has focus (~1.89 wake-ups/s), killed after
about 10 seconds without input; caret stays solid. No caret timer with list focus.
Shell watchdog exists only during pending shell work. CPU sampled via process times;
actual wake-ups were not captured with ETW. Initial earlier idle sample included
15.625 ms CPU; settled final sample above was zero.
