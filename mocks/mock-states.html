Window states

Each section is the main window in one state. Drawing rules: only fills, strokes, lines, text and bitmap icons. No shadows or blur: popups are a filled rounded rect with a 1 px border.

Theme

Row states

One row (22 px) in every state. Hover and selected are solid fills (hover, selected, selected_inactive); focus is a 1 px inset stroke in focus drawn on top of whatever fill the row has. Text colours never change between states: text for the name, text_dim for the other columns (both pass 4.5:1 on every fill).

Path bar: edit mode

Click the bar, Ctrl+L or Alt+D. Breadcrumbs become a text field with a focus border; folder suggestions drop down in a popup (Tab completes, Enter goes, Esc restores the breadcrumbs). The caret is solid, not blinking, so an idle window needs no timer.

Loading

No spinner. A 2 px accent line sits on the bottom edge of the toolbar (under the path bar) and its width grows each time a batch of entries arrives (repaint on the batch message, no timer). Rows appear as they stream in; the status bar counts up. Width formula suggestion: 1 - exp(-count / 20000), since the total is unknown. The line disappears when the listing is complete.

Empty folder

Header stays; a centred 40 px folder bitmap, one line of text, one hint line in text_dim with the shortcut in a stroked key cap.

Filter as you type

Typing in the list (or Ctrl+F) focuses the filter field and narrows the list live, case-insensitive substring. The match is a solid highlight rect behind the characters. The status bar says how many rows match. Esc clears. Folders still come first.

Context menu popup

Opened at the pointer on the focused row. 24 px items, 248 px wide, icon column, shortcut right-aligned in text_dim, 1 px separators, disabled item in text_disabled, hovered item in selected, Delete in danger. Shell verbs live behind “Show more options” (the S4 native menu); see the open decisions in the report.
