Command palette

Ctrl+Shift+P opens a 640 px panel, centred, 56 px from the top of the window. No dimming scrim (the kit has no alpha-free way to dim cheaply and File Pilot does not either): the panel is a filled rounded rect with a 1 px popup_border stroke, like every popup. The text field has focus; the caret blinks only while it is focused and stops after about 10 s. A prefix typed in the field switches the mode, and the mode strip under it shows all four so nobody has to remember them. Selected row = selected fill plus the 2 px accent bar used in the sidebar.

Theme Try it (live, commands mode)

1. Opening state: recent commands first

Empty field, commands mode. The five most recently run commands come first under “Recent”, then everything else in a fixed order (category, then name). Each row: icon, name, category, current shortcut chips (or a dashed unbound chip). The shortcut shown is always the user's current binding, so it follows rebinding and profile changes. Custom commands carry a small accent Custom tag. A thin scrollbar appears when the list is longer than the panel (the panel is capped at about 10 rows).

2. Fuzzy match with highlighted letters

Typing rn: every command whose name contains those letters in order matches. The matched letters get the same solid highlight rect as the folder filter. Ranking: word starts and consecutive letters score higher, shorter names win ties, and commands run recently get a bonus, so “Rename” is first. Matching is on the name only; the category and shortcut are shown but not searched (searching ctrl+t also matches the shortcut chip: see open question 2 in the report).

3. Mode /: go to path, with completion

Typed /C:\Users\Alex\D. Folders that continue the typed path are listed with the typed part dimmed and the rest bold (Tab completes to the highlighted one, Backspace on a path separator goes up one level). Below: recent folders. UNC and drive-less paths work the same. If the typed path does not exist the first row says so instead of failing silently (not drawn here). This replaces nothing in the path bar: Ctrl+L still edits the breadcrumb in place; this is the same completion reachable from the palette.

4. Mode #: filter this folder

Same engine as Ctrl+F: case-insensitive substring, folders first. The list behind the palette is filtered live as you type; this panel previews up to six matches with the matched text highlighted and the status-style count in the first row. Enter keeps the filter in the folder and closes the palette; Esc clears it.

5. Mode @: jump to an open tab

All open tabs of all panes. The current tab carries an accent Current tag, others show which pane they sit in, and Alt+1 … Alt+9 are the direct shortcuts. Typing after @ fuzzy-matches the tab title and the path.

6. Empty state (first use, no recent commands)

Nothing typed and no history yet: instead of an empty list, a short prefix cheat sheet. After the first command is run the opening state of section 1 replaces it.

7. No results

One line saying what was searched, one hint line, and an escape hatch: create a custom command with that name (opens Settings › Context menu with the form prefilled). Backspace edits the search; Esc closes.
