Proposed layout & shortcut defaults

  • Docked pane width: 320 px default, min 220 px, max 50% of window (double-click splitter resets to 320 px; persisted in config.toml).
  • Toggle preview pane: Alt+P (toolbar button + command preview.toggle).
  • Quick Look: Space when the file list owns focus (never steals Space inside filter/rename/path text inputs). Space or Esc closes; ←/→ steps items.
  • Dual-pane layout: one shared preview pane docked right of the window, following the active pane’s focused file (same rule as the shared sidebar).

Worker, limits & memory budgets

  • Selection debounce: 50 ms while arrow-stepping; generation counter drops stale worker replies (PLAN.md §3 rule 1).
  • Loading state: shown only after 80 ms (2 px accent line + flat skeleton rects, zero animation timer).
  • Text cap: 64 KB read limit (UTF-8 / UTF-16 BOM sniff, NUL-byte guard) with truncation banner.
  • Hex cap: 16 KB (1,024 rows × 16 B); 16 B/row when ≥420 px wide (and in Quick Look), auto-switches to 8 B/row or scrolls in narrower docked widths.
  • Image cache: decoded at max_px = 2048 into a bounded premultiplied-BGRA LRU capped at 32 MB (evicted on cap, cleared on close).
