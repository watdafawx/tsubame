Settings, keys and control states

Settings is a page in a tab (Ctrl+, or the gear in the command palette), not a modal. Left: nav list with a “Find a setting” field. Right: one scrolling page, 880 px max, grouped rows (label and one-line description on the left, control on the right). Everything applies the moment it changes, so there is no Save or Apply button; the few things that need a restart say so in a banner. The mock shows each page unscrolled and at full height (the real page scrolls; the thin scrollbar on the right is drawn). Nine entries in the nav: General, Appearance, Context menu, Keys, Updates, Default file manager and Advanced are drawn; Panes and tabs and Search are nav entries only for now.

Theme

General

Start folder (with a Browse field that appears for “A specific folder”), restore session, hidden and protected system files, file extensions, and delete behaviour: Recycle Bin vs permanent, plus the confirm toggle.

Appearance

All 19 themes as swatch cards: the two Tsubame themes plus the 12 dark and 5 light palettes shared by hopper and spotifast (spotifast loads the same Catppuccin, Nord, Rosé Pine and Ristretto files, so the two apps need no extra entries). Each card is a miniature of the app in that theme: sidebar and header in panel, rows in text, a selected row in the accent, and the accent dot. Hover previews the theme in the whole window, click keeps it (hopper’s behaviour). The current card has a 2 px accent outline and a check. Below: accent colour, row density as a segmented control with three live previews, zebra, font size slider and the icon-style choice.

Context menu: editor

Left: every entry in order. Grip = drag to reorder (the dragged row is lifted in selected with a focus outline; the accent line with a dot shows the drop position). Eye = show or hide (a hidden row is dimmed and drops out of the preview). A name is renamed in place (the row in the “Tools” submenu is being edited, caret shown). Submenus fold their children under a guide line. The tag says where an entry comes from: Built-in, Windows (shell), Custom, or From Nilesoft. Right: a live preview using the popup drawing from M1.

Context menu: add a command, import from Nilesoft Shell

“Add custom command” opens an inline form: name, program, arguments with {path} and {selection} placeholders explained underneath, where it shows (files, folders, background) and which submenu it goes in. “Import from Nilesoft Shell…” reads a .nss file and shows a result summary: here 14 imported, 2 skipped, with the reason and line number for each skipped item. The import can be undone in one click; the original file is never modified.

Keys

All commands grouped by category (the same table the command palette uses), with search, current shortcut chips (a command has up to two bindings, the second after “or”), and a profile switch: Tsubame default, Explorer-like, Total Commander-like. A shortcut that differs from the profile gets an accent bar on its row and a reset icon. The hovered row shows its actions: record, clear, reset. “Reset all” is a danger button and asks to confirm (see states).

Keys: recording a shortcut, with a conflict

Click a row (or its pencil) and the row expands: a field with a focus border shows the keys as you hold them, in outlined key caps. When the combination is already taken, a danger-bordered box says which command has it and what will happen; the user chooses “Assign here, unbind there”, picks another, or cancels. Esc cancels, Backspace clears this shortcut. The caret in the field follows the 10 s blink rule.

Updates

Current version, last checked, Check now, channel, check on start, automatic install, roll back to the previous version, and the integrity block with the verified-signature line. Content follows docs/updater.md (Settings › Updates wiring list).

Updates: a new version is available

After a check finds 0.5.0: a banner with the release notes link and Download and restart, a progress bar with Cancel while downloading, and a dot on the “Updates” nav entry.

Default file manager

Opt-in, off by default. The status line always says what is true now (read back from the registry): “Tsubame handles folder opens: Off”. A plain explanation, three independent switches, an honest list of what still opens File Explorer, a Restore button that is always visible, and the fail-safe note. Wording follows docs/research-default-explorer-defender.md sections 5.3 and 5.4.

Advanced

Cache sizes with hard caps (every cache in Tsubame has one), live memory numbers, logging level, and Reset all. Shown with a “Restart needed” banner after the GPU setting was changed.

Control states

Toggle, segmented control, dropdown (closed and open), slider, text field (empty, focused with caret, error, disabled), the caret blink rule, buttons, the Reset-all confirm (two stages) and the restart banner. No toast for “Settings saved”: settings apply live.
