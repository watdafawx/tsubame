Tsubame draws its own right-click menu. It reads the shell’s menu (IContextMenu::QueryContextMenu) on a worker thread, draws every row itself in Tsubame’s look, and invokes the clicked row by command id. You can hide, rename, reorder and add entries. Pick a state in the bar (or scroll: All states). Theme, density, font scale, the quick row and the accelerator underlines are live switches that apply to every state. Page-only parameters for screenshots: ?only=<id>&theme=light&dens=26&sc=125&quick=1&ul=0. Review notes (dashed outlines, callouts, grey labels) are not part of the app.
