Sidebar, dual pane, drag states

Task U3 mock (1 of 2; inline rename is mock-rename.html). Everything here is flat rects, 1 px strokes, text and the same bitmap icons as M1: nothing needs a shadow, blur or animation. Density buttons mirror Density in the kit (22 / 26 / 30 px rows, text x1 / x1.08 / x1.17); sidebar and chrome heights stay fixed, as in the app today.

Theme Density

1. Sidebar

Sections top to bottom: Pinned (your bookmarks), Quick access (known folders), Recent (collapsible, Clear in the header), This PC (drives with a 3 px free-space bar: accent, danger when under 10 % free: Games G: here), Network. Chevron collapses a section. Hover row = hover fill; current folder = selected_inactive fill + 2 px accent tick (same as M1). On a hovered pinned row the star turns into the unpin glyph (click = unpin) and a grip appears on the right (drag = reorder). Footer: collapse button + Ctrl+B. The wide window is 840 px high so nothing scrolls; the real sidebar scrolls with the thin scrollbar when it overflows.

2. Bookmark context menu

Right-click (or the menu key) on a pinned row. Stub only, same popup as the file menu (24 px items, 248 px, popup fill, 1 px border). Rename changes the label shown in the sidebar, not the folder. Open in other pane switches to a split first if there is none. Delete key unpins without a prompt (re-pin is one click; no data is lost).

3. Drag to reorder / pin by dropping

Dragging the blink bookmark by its row: the source row greys out (text_disabled), a 2 px accent line with a dot shows where it lands, a small drag image follows the pointer. The same line appears when you drag a folder from a file list into the Pinned section (between rows = pin there; dropping onto a row = copy/move into that folder, see the drag shots below).

4. Collapsed sidebar (icons only, 48 px)

Ctrl+B or the footer button. Section headers become 1 px separators, drives keep a 3 px bar under the icon, Recent and Network shrink to one icon each (click opens a flyout list: not mocked). Hover shows a tooltip (popup fill, 1 px border) to the right with the name; for drives it adds the free space. The list gets the 160 px back.

5. Resize handle

The right edge is a 5 px hit strip (the kit’s splitter_w). Hover: 3 px scrollbar_hover line; dragging: 3 px accent line and a small chip with the live width. Range 140 to 360 px; dragging below 120 px snaps to the 48 px collapsed mode. Double-click resets to 208. Here Recent and Network are folded to show the section arrows.

6. Dual pane, vertical split

Title-bar switch: single / side by side / stacked, plus the sync-scroll toggle (off = dim with a slash; on = accent, shown in shot 8). With two panes each pane owns its tab strip, toolbar (back / forward / up, path bar, filter button), list and status bar. Active pane: 2 px accent line under its path bar, normal selection colour, focus ring, F5/F6 hints in its status bar when something is selected (the label says the direction). The other pane keeps its selection in selected_inactive, no focus ring, and shows free space instead. The sidebar is shared and follows the active pane. In dual mode the sidebar starts under the title bar (single mode keeps the M1 layout, toolbar across the top). Panes under 640 px hide the Type column.

7. Dual pane, horizontal split

Same panes stacked. Each pane costs 118 px of chrome (tabs 30 + toolbar 40 + header 24 + status 24), so use a taller window; the F5/F6 hint says “to bottom” / “to top”. Bottom pane is the active one here.

8. Splitter drag, sync scroll on

Hover: 1 px scrollbar_hover. Dragging: 3 px accent line plus a chip with the split (62 / 38). Min pane 240 px, double-click resets 50 / 50, Ctrl+\ toggles single/split. The right pane drops its Type column automatically at this width. Sync-scroll is on here (link icon in accent): wheel and keyboard scrolling move both lists by the same row offset.

9. Dragging files over a folder row

4 selected files dragged inside the left pane onto the Invoices folder. Target row: selected fill + 1 px focus inset stroke. Drag image: file icon, first name, count badge. Tooltip: bold action (“Move to Invoices”: same drive moves) and the modifier hints. Plain Windows rules: same drive = move, other drive = copy, Ctrl = copy, Shift = move, Alt = shortcut.

10. Dragging files over a sidebar bookmark

Same files dropped onto the blink bookmark (D: is another drive, so the default flips to Copy). Row highlight identical to the folder row. Drops between pinned rows pin instead (shot 3).

11. Dragging files over the other pane

Over the right pane’s empty area or any file row: the whole pane gets a 2 px focus frame and the tooltip names the target folder (“Copy to Invoices-2026”). Over a folder row inside that pane the row highlight from shot 9 wins instead. Releasing on the tab strip of either pane drops into the tab’s folder.

12. Keyboard hints

One small card for the help popup (F1 or ?, listed per context). The same key caps are used inline in the status bar and menus; nothing else on screen needs a legend.
